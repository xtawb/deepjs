DeepJS reads the JavaScript that passes through Burp the way the browser's engine would, instead of searching it for quoted paths, and reports the API a front end talks to: each request with its method, path, query-parameter names, body field names and header names.

Features

  • API calls from fetch, axios, jQuery, XMLHttpRequest, Angular HttpClient, Nuxt $axios, request-config objects, WebSocket, EventSource and sendBeacon. URLs built from variables, template literals, class properties (this.host + "/reviews") and conditional pieces are resolved; unknown parts are shown as {placeholders}.
  • Hidden scripts: the chunk-name function of webpack, Next.js and Vite builds is evaluated, so the chunks no page has loaded yet are listed and can be requested through Burp with one click. Only hosts that have already served a script are contacted, optionally in-scope only.
  • Source maps: referenced maps are fetched through Burp and the original sources are analysed with the same engine.
  • Secrets: 35 credential formats and values assigned to secret-bearing names. Keys that are public by design (Stripe publishable keys, Firebase web configuration, Supabase anon keys, Algolia search keys) are labelled as such instead of being reported as leaks. Values are masked in the user interface.
  • Hosts, client-side routes, GraphQL operation names and npm package names found in the code.
  • Send to Repeater builds a request skeleton from a finding: method, query names, a JSON body with the field names.
  • Analyse proxy history, and an "Analyse with DeepJS" context-menu item.

Usage

  1. Browse the target through Burp. Findings appear in the DeepJS tab as responses arrive.
  2. Open "Hidden scripts" to see what the code refers to that has not been loaded; "Fetch now" requests it.
  3. Select rows under "API calls" and choose "Send to Repeater".

The extension has no dependencies. Analysis runs on its own thread and makes no network requests of its own: hidden scripts and source maps are requested through Burp, and only when those options are enabled.
